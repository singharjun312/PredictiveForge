AI Security & Governance — Part 8 of 8: ISO/IEC 42001:2023 AI Management System Compliance Validator & Supply Chain Security Scanner

Synopsis

Implemented an automated ISO/IEC 42001:2023 AI Management System compliance validator covering Clauses 4–10 with 15 checks, weighted risk scoring, and downloadable HTML compliance reports, alongside a Supply Chain Security Scanner that checks installed Python packages against a curated CVE database and generates a Software Bill of Materials (SBOM).

Summary of Work Experience

Engineered two governance and security modules for the AI platform: an ISO/IEC 42001:2023 compliance engine validating notebooks across Context (Clause 4), Planning (6), Support (7), Operation (8), Performance Evaluation (9), and Improvement (10) with severity-weighted scoring (Critical/High/Medium/Low) and risk-rated HTML compliance reports; and a Software Composition Analysis (SCA) scanner enumerating all installed packages against a curated NVD CVE database, producing SPDX-inspired SBOMs with remediation guidance. Both modules are integrated into the platform's unified compliance dashboard with downloadable audit artifacts. Directly applicable to CISSP Domain 3 — Security Architecture and Domain 8 — Software Development Security.
