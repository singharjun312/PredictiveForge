# Sample Artifacts

Real outputs generated by the PredictiveForge platform during a test session.
These demonstrate the governance and compliance capabilities of the platform.

---

## Files

### `compliance_report.html`
A full AI governance compliance report generated by the platform's built-in
compliance scanner. Covers:
- **NIST AI Risk Management Framework (AI RMF)** — control categories mapped
  to notebook/pipeline behaviour
- **EU AI Act** — alignment checks with risk ratings
- Findings, recommendations, and a downloadable HTML report

Open in a browser to view the formatted report.

### `security_cert.json`
A security verification certificate produced after a code generation cycle.
Confirms the following OWASP LLM Top 10 controls passed:
- **LLM01** — Prompt Injection prevention (AST import whitelist enforced)
- **LLM02** — Insecure Output Handling (structural safety via `self_check()`)
- Data minimisation pre-scan and deterministic seeding checks

### `audit_log_sample.jsonl`
An 86-entry sample audit trail from a platform session. Each line is a
structured JSON event covering:
- Code validation results (forbidden imports blocked, self_check verified)
- PII masking events (columns detected, SHA-256 hashes before/after masking)
- Training run records (algorithms, dataset metadata, governance notes)
- OWASP control references per event

All data in this log is synthetic test data — no real user data is present.
